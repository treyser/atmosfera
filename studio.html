Підключи GitHub

Майстерня сама записує зміни в репозиторій treyser/atmosfera. Для цього їй потрібен твій особистий ключ доступу. Його бачиш лише ти: він зберігається тільки в цьому браузері.

  1. Відкрий github.com → Settings → Fine-grained tokens → Generate new token.
  2. Назва — будь-яка (наприклад, «Майстерня»), термін — скільки хочеш.
  3. Repository access → Only select repositories → atmosfera.
  4. Permissions → Repository permissions → Contents → Read and write. Більше нічого не треба.
  5. Натисни Generate token, скопіюй ключ (починається з github_pat_) і встав нижче.
Обери картку зліва або натисни «＋ Додати».
